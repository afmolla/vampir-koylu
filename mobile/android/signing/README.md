# Release imzası (KİLİTLİ — değiştirme)

Tüm APK'lar **`release.keystore`** ile imzalanır. CI yeni anahtar üretmez.

- Parmak izi: `SIGNING_FINGERPRINT.txt`
- Detay: `SIGNING-LOCKED.md`

Eski (farklı imzalı) uygulama yüklüyse kullanıcı **bir kez kaldırıp** yeni APK kurmalı; sonrasında güncellemeler çakışmaz.
